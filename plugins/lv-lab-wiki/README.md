# LV Lab Wiki Plugin

This package contains the `ask-wiki` retrieval and answer policy. It does not
contain a copy of the Wiki, an MCP server, or a background service. At question
time, the Skill reads the public deployed Wiki over HTTPS, so users do not need
to clone or update the Wiki repository.

Standalone Skill source:

```text
https://github.com/LV-Robotics-Lab/lab-wiki/tree/main/plugins/lv-lab-wiki/skills/ask-wiki
```

The Plugin homepage contains user-facing installation, update, removal, and
troubleshooting instructions.
