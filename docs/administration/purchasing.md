# 采购流程

本流程统一各组的需求确认、选型、周末汇总、下一周采购、到货认领和入库记录，减少重复采购、型号不兼容、漏买配件和采购后闲置。

!!! info "每周采购节奏"
    每组每周只提交一份 Excel 采购表和一个总购物车分享链接。周六或周日统一汇总给采购协调人，本周汇总的申请安排在下一周采购；不同周的采购批次不混合。

## 表格入口

- [采购需求表（第一张表）](https://app.notion.com/p/1a9a5a3a6fa1823c982a81b0b85292a9?v=9a9a5a3a6fa183ad91c38825a9477526&source=copy_link)：每组每周提交一份 Excel，并登记本周统一采购需求。
- [已下单表（第二张表）](https://app.notion.com/p/3b995c72020b8041a0cbed31aa08759c?v=3b995c72020b80c583df000c4f17b9e5&source=copy_link)：采购完成后更新对应采购周的已下单信息；到货后由申请组逐项拍照并更新记录。

两个表由 Notion 权限控制访问。Wiki 只提供入口，不复制订单、照片或其他采购明细。

## 角色分工

| 角色 | 职责 |
|---|---|
| 各组成员 | 共同确认需求、货比三家、讨论选型并完成可行性调研 |
| 各组采购提交人 | 整理本组当周唯一一份 Excel、核对物品和购物车，并提交总分享链接 |
| 采购协调人 | 周末汇总各组提交，检查字段、重复采购、购物车一致性、调研和审批状态 |
| 采购执行人 | 按确认后的周批次清单在下一周下单，并将到货包裹放到公共区域 |
| 申请组 | 认领并拆包，逐项核对、拍照、更新对应周的 Notion 记录并对本组物品负责 |

## 提交前准备

- 同组成员已共同确认需求和选型，不由个人单独决定。
- 每项物品都有明确用途、预计使用人和使用时间，并确认确实需要采购。
- 已核对现有库存，确认没有可复用或可共享的同类物品。
- 已尽可能货比三家，完成型号、规格、数量、兼容性、必需配件和交付调研。
- 已确认不会到货后才发现缺少配套物品；所有必需物品应在同一周申请中列全。
- 金额较高的物品已按实验室现行审批要求取得事前确认。
- 能够享受 `SG199` 包邮的物品必须选择可包邮方案；无法包邮的特殊需求已在 Excel 中说明原因。

## 提交流程

1. 组内共同明确用途和完整需求，尽可能比较至少三家供应商或合理替代型号，确定型号、数量、金额和必需配件。
2. 由本组采购提交人整理当周唯一一份 Excel。每项必须填写物品名称、数量、型号、金额、用途、商品链接和申请组别。
3. 将本周确定采购的所有物品加入对应平台的同一购物车，核对型号、数量、配件、价格和包邮条件后生成一个总购物车分享链接。
4. 在周六或周日将 Excel 和总购物车分享链接作为一个完整申请统一提交给采购协调人。个人通过文字、聊天或其他形式单独提交的需求不进入采购流程。
5. 采购协调人周末汇总各组申请，检查字段完整性、重复采购、购物车与 Excel 是否一致、调研可行性、包邮条件和审批状态；不符合要求的申请退回申请组完善。
6. 本周汇总的申请在下一周按独立批次采购。采购执行人不得将不同周的申请混合下单，也不得在缺货、涨价或规格变化时自行替换型号。
7. 采购完成后，将实际采购信息更新到对应采购周的“已下单表”，保持每周记录独立。

## 可行性与选型要求

每项采购在提交前至少确认：

- **实际用途：** 对应项目、实验或维护任务明确，预计使用人和使用时间明确。
- **货比三家：** 已比较尽可能多的供应商或合理替代型号，并说明当前选型在功能、价格、交付、售后或维护方面的理由。
- **兼容性：** 与现有设备、软件、接口、尺寸、电源、材料和实验方案匹配。
- **完整性：** 数量、线材、转接件、安装件、耗材和其他必需配件已一次性核对，避免到货后发现漏买。
- **供应与运费：** 商品链接、库存、交付时间、售后条件和包邮方案已经核对。能够享受 `SG199` 包邮的物品必须选择包邮；特殊需求不能包邮时，必须在 Excel 写明原因并接受复核。

金额较高的物品还必须更充分地比较备选方案、验证关键兼容性、写明使用计划，并按实验室现行审批规则取得确认。Wiki 不另行规定金额阈值。

## 到货、认领与 Notion 更新

1. 采购执行人将到货包裹放到公共区域，并保留可供申请组识别的申请组或订单信息。
2. 申请组自行认领并拆包，逐项核对物品名称、型号、数量、金额对应关系、必需配件和外观状态。
3. 申请组为每项物品拍照，并在对应采购周的“已下单表”中更新到货和照片记录。
4. 确认实物、照片和 Notion 记录一致后，完成入库并将物品移至指定存放位置。申请组对自己采购的物品负责。

发现错发、漏发、破损或无法使用时，暂停入库，保留包装和照片，联系采购协调人处理，不自行替换或关闭记录。

## 核验清单

- [ ] 本组本周只提交了一份 Excel 和一个总购物车分享链接。
- [ ] 每项物品的名称、数量、型号、金额、用途、商品链接和申请组别完整。
- [ ] 个人没有通过文字、聊天或其他零散形式单独提交需求。
- [ ] 购物车中的型号、数量、配件、金额和包邮条件与 Excel 一致。
- [ ] 已完成货比三家、用途和可行性调研，必需物品没有遗漏。
- [ ] `SG199` 可包邮的物品已选择包邮；特殊例外已在 Excel 说明并复核。
- [ ] 本周申请安排在下一周独立采购，没有与其他周混合。
- [ ] 采购完成后已更新对应周的“已下单表”。
- [ ] 到货物品已由申请组逐项拆包、拍照并更新 Notion。

## 异常处理

- **个人单独提交或提交多份：** 不进入汇总，退回所属组统一整理为当周一份 Excel。
- **错过周末汇总或材料不完整：** 补齐后进入下一次每周采购周期；完成前不采购。
- **缺少用途、调研、配件或包邮例外说明：** 退回申请组补充，补充完成后重新汇总。
- **共享购物车链接无法访问或与 Excel 不一致：** 由申请组重新生成链接并核对商品、型号、数量和金额。
- **商品缺货、涨价或规格变化：** 暂停该项采购，退回申请组重新确认，不直接购买替代品。
- **重复采购或已有可用库存：** 暂停该项，确认共享或复用方案后再决定是否采购。
- **到货错发、漏发或破损：** 暂停入库，保留包装和物品照片，通过采购协调人联系供应商处理。
- **包裹无法认领或 Notion 无法更新：** 保持物品原状，联系采购协调人核对申请组、周批次和记录。

## 信息安全

两个 Notion 表是经确认的公开入口，实际 Excel、购物车分享链接、订单明细、付款信息、个人地址和采购照片由 Notion 或实验室批准的受控渠道管理。Wiki 不保存个人信息或未审核的内部记录。
