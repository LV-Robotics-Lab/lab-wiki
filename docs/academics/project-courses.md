# 课程项目、Capstone 与 Dissertation 申请

!!! warning "以当前学期官方信息为准"
    课程名额、适用专业、Topic、审批人和截止日期会随学期变化。群聊和共享表格只能作为线索，最终状态必须在当前学期的官方系统和课程通知中核验。

## 用途

说明通过实验室研究项目申请 ME5100、ME5400、Capstone、Dissertation 或其他课程项目时的通用准备和确认流程。

## 前置条件

- 在当前学期课程页面确认课程代码、资格、学分、时间表和注册窗口。
- 确认研究方向与课程学习目标匹配。
- 评估线下实验、课程作业和科研投入之间的时间冲突。
- 准备个人背景、相关技能、兴趣方向和可投入时间。

## 操作步骤

1. 在官方课程系统确认自己具备申请资格，不以群聊报名或共享表格为准。
2. 从[研究方向与项目机会](../projects/index.md)中选择感兴趣的方向。
3. 通过受控通讯录联系对应的 **项目协调人**，提交背景和意向。
4. 与负责人讨论任务、线下出勤、交付物、知识产权和数据保密要求。
5. 如课程要求 approve letter、导师批准或 self-propose 文件，在当前学期截止日期前取得正式确认。
6. 在官方系统完成选课或项目提交，并保留提交回执。

## 申请材料建议

- 姓名和学校账户信息，仅通过获批表单提交
- 课程代码、项目方向和当前学期
- 相关课程、工程或研究经历
- 可投入时间及线下实验可用性
- 与项目匹配的技能和预期学习目标

## 验证

- 官方系统显示正确的课程或项目状态。
- 已收到课程方、导师或项目负责人的正式确认。
- 时间表与其他课程、工作和线下实验安排没有未解决冲突。
- 个人信息没有被写入公开 Wiki、Issue 或代码仓库。

## 故障排查

- 共享表格有名字但系统无记录：以官方系统为准，并联系课程管理员核对。
- 名额或 Topic 与群聊不一致：使用当前学期课程通知重新确认。
- 尚未取得 approve letter：不要把口头意向当作已批准，尽快联系负责人。
- 课程和项目时间冲突：在注册截止前与双方负责人调整，不要等到正式启动后处理。
- 未选上但仍有兴趣：通过受控意向表登记，等待负责人确认后续安排。
