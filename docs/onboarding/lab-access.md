# 实验室门禁申请

## 用途

申请进入实验室 `COM2-0106` 的门禁权限。

## 申请前准备

- 准备可登录 MySoC 的 NUS 账号。
- 向实验室管理员确认 Supervisor SoC ID。

## 申请入口

[打开门禁申请表](https://mysoc.nus.edu.sg/app/eform/forms/formE.php)

!!! info "填写提示"
    - 进入表单后，按页面要求填写个人信息、门禁期限和申请原因。
    - Supervisor SoC ID 当前应向实验室管理员确认。
    - 校外打不开页面时，尝试连接 NUS VPN。

## 填写信息

- Supervisor SoC ID：`<SUPERVISOR_SOC_ID>`
- 实验室地点：`COM2-0106`

## 操作步骤

1. 打开申请表并填写页面要求的信息。
2. 填写上方的 Supervisor SoC ID 和实验室地点。
3. 核对内容后提交申请。

## 验证

确认页面显示申请已成功提交，并按页面提示查看后续状态。

## 故障排查

需要连接校园网，或者NUS VPN
连接 NUS VPN 后仍无法访问或提交时，联系实验室管理员。
