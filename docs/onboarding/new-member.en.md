# New Member Checklist

## First week

- [ ] Join the main laboratory communication channels
- [ ] Confirm your direct mentor and administrative contact
- [ ] Request the required accounts
- [ ] Read the basic laboratory guidelines
- [ ] Arrange an initial workspace orientation

## Completion criteria

You should know who to contact for technical and administrative questions and where documentation should be updated.
