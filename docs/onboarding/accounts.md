# 账号与权限

## 用途

统一说明实验室常用账户、算力、远程网络和内部工具的申请入口，避免在群聊和公开文档中传递凭据。

## 前置条件

- 已加入明确的实验室项目或课程项目。
- 已确认所需资源、用途、权限范围和使用期限。
- 使用个人账户申请，不与他人共用身份或凭据。

## 申请模板

| 资源 | 申请对象 | 所需信息 | 说明 |
|---|---|---|
| GitHub | Wiki 管理员 | GitHub 用户名、项目、仓库权限 | 使用个人 GitHub 账户 |
| AI API | AI 服务管理员 | 项目、用途、模型和用量估算 | 见 [AI API 申请与使用](ai-api-access.md) |
| 算力 | 算力管理员 | GPU、卡数、时长和费用来源 | 见 [算力资源申请与选择](../resources/compute-access.md) |
| 远程接入 | 网络管理员 | 工作设备、项目、目标资源和期限 | 见 [远程接入与自组网申请](../resources/remote-access.md) |
| 文件存储 | 数据存储管理员 | 项目、数据类型、容量和成员 | 见 [研究数据存储与归档](../resources/data-management.md) |
| 内部工具 | 对应负责人 | 用途、所需权限和期限 | 通过受控通讯录申请 |

## 操作步骤

1. 选择上表中的资源类别并准备所需信息。
2. 通过实验室受控通讯录联系对应管理员。
3. 管理员确认项目、权限和使用期限。
4. 通过密码管理器或一次性安全渠道接收敏感配置。
5. 完成最小验证后保存申请记录，不保存真实凭据。

## 验证

- 个人账户可以访问获批准的资源。
- 无法访问未获授权的项目和服务。
- Wiki、Issue、日志和代码仓库中没有真实凭据。

## 故障排查

- 权限不足：向对应管理员提供项目和错误摘要，不发送密码或 key。
- 项目变更或离组：主动申请调整或撤销权限。
- 凭据疑似泄露：立即停止使用并联系管理员轮换。

!!! warning "敏感信息"
    Wiki 可以记录获准公开的服务地址、主机名和 IP，但不要保存密码、私钥、API key、token、Auth ID、远程控制密码或 `.env` 文件。
