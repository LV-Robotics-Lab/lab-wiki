# 实验室仓库导览收录设计

## 背景

现有 `LV-Robotics-Lab-repository-guide.md` 汇总了 LV Robotics Lab 组织仓库的导航关系、各研究与真机方向的主入口、仓库角色、治理快照和建议的信息架构。用户已明确批准公开其中的私有仓库名称、权限快照与内部架构信息，并选择把该指南放入 Wiki 的“项目协作”栏目。

## 目标

- 将现有仓库导览作为正式 Wiki 页面发布，保留全部实质内容、Mermaid 图、表格、仓库链接和已批准的内部信息。
- 为新成员提供从实验室规范到组别主入口、设备层和参考仓库的明确阅读路径。
- 同步提供中文和英文页面，并保持内容结构、导航和维护信息一致。
- 将页面加入 AI 检索索引，使用户可通过仓库名、组别和“仓库导览”等关键词发现该页。

## 非目标

- 不重新盘点 GitHub 组织，也不改变原文截至 `2026-08-16` 的数字、仓库归属或治理建议。
- 不执行原文提出的 Team、权限、Custom Properties、归档或仓库删除操作。
- 不修改被引用仓库的 README、CODEOWNERS、可见性或其他设置。
- 不在本次改动中补写“非真机组统一协作模式”等其他尚未落入当前本地分支的页面。

## 信息架构

新增顶层导航栏目“项目协作”，英文为 “Project Collaboration”。栏目内新增页面“实验室仓库导览”，英文为 “Lab Repository Guide”。

文件位置：

- `docs/project-collaboration/repository-guide.md`
- `docs/project-collaboration/repository-guide.en.md`

中文标题由“LV Robotics Lab 仓库导览（内部版）”调整为“LV Robotics Lab 仓库导览”。公开授权已经确认，因此不再保留容易误导读者的“内部版”标签；正文的实质信息不删减。

## 页面内容

中文页以源文件为基准，保留以下结构和信息：

1. 一句话导航和 Mermaid 组织关系图。
2. `2026-08-16` 组织盘点与访问治理快照。
3. 主入口、设备或能力层、定制上游、参考或待治理四种仓库角色。
4. 通用层、仿真组、世界模型组和真机组各分支的仓库导航与边界。
5. 待认领、待归档或需重新定位的仓库及已完成退役记录。
6. 建议的 GitHub Teams、Custom Properties 和主入口 README 结构。
7. 完整仓库主归属索引和维护规则。

英文页完整翻译中文内容，保留仓库名、分支名、属性名、路径、链接、数值和日期，不增加或省略约束。仓库与技术标识继续使用原有英文拼写。

两页页尾增加维护信息：

- 维护者：Wiki Team
- 最后核验：`2026-08-16`

## 公开与内容边界

- 用户已明确批准公开原文中的私有仓库名称、组织成员数量、权限快照和内部架构信息。
- 该批准不扩展到源文件未包含的凭据、个人身份信息或其他受限资料。
- 页面不引入密码、token、私钥、个人联系方式或新的内部端点。
- 原文中的动态盘点数据保留快照日期，不表述为持续实时状态。
- 对未来治理动作继续使用“建议”“待确认”等措辞，不把提案误写为已完成事实。

## 导航与检索

- 在 `mkdocs.yml` 中增加“项目协作”导航及英文翻译，并将仓库导览页加入该栏目。
- 在 `docs/assets/data/ai-index.json` 中增加中英文配对条目。
- 两个索引条目使用 `wiki-team` 作为维护者，`last_verified` 为 `2026-08-16`，并设置可覆盖仓库导览、GitHub、仿真、世界模型、真机和治理的中英文关键词。
- 更新索引的 `generated_at`，保持 JSON 结构和中英文 `alternate_url` 双向对应。

## 验证

- 对照源文件检查中文正文没有实质内容缺失，英文页与中文页章节、表格、仓库列表、链接、数值和日期一致。
- 确认 Mermaid 代码块可由现有 `pymdownx.superfences` 配置正常构建。
- 运行 `python -m unittest` 验证 AI 索引覆盖和其他现有测试。
- 运行 `mkdocs build --strict`，确保双语页面、导航、链接和 Markdown 均可严格构建。
- 运行 `git diff --check` 并审查 `git diff`，确认没有无关文件或未获批准的信息进入改动。
